### 🚀 Key Projects

#### 🤖 [Jasas AI — Autonomous Executive Secretary](https://github.com/SultanQadry/AI-Executive-Secretary)
> **Production-grade AI executive assistant with zero-trust security gates.**
- **Action Policy Engine:** Three-tier authorization (`ALLOW` / `CONFIRM` / `DENY`) preventing unconfirmed actions via Redis-parked 15-minute confirmation loops.
- **Voice & Messaging:** Deepgram speech-to-text with HMAC-signed WhatsApp webhook processing.
- **Distributed Backend:** Asynchronous FastAPI, Celery worker cluster, Redis locking, and automated S3 database backups.
- **Tested & Verified:** Comprehensive test suite (160+ unit & integration tests) running on GitHub Actions CI.

```
Stack: Python 3.12 · FastAPI · Celery · Redis · PostgreSQL · GCP · AWS · Docker
```
